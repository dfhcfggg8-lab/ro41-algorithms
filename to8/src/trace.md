# Трассировка строковых методов C#

## 1. `Trim()` и `Split(';')`

Исходная строка:

```csharp
string s = "  Ахметов Ерлан;85 ";
```

После `s.Trim()` удаляются пробелы в начале и конце строки:

```text
Ахметов Ерлан;85
```

После `Split(';')` получаем массив из двух элементов:

| Индекс | Элемент массива | Длина |
|---:|---|---:|
| 0 | `Ахметов Ерлан` | 13 |
| 1 | `85` | 2 |

Пробел между именем и фамилией входит в длину первого элемента.

## 2. `int.TryParse()` и `TryParseScores`

Исходная строка:

```csharp
string line = "Иванов Пётр;70;85;x";
```

После `Split(';')` получаем четыре части:

| Индекс | Часть | `int.TryParse()` | Значение `out` |
|---:|---|---|---:|
| 0 | `Иванов Пётр` | `false` | 0 |
| 1 | `70` | `true` | 70 |
| 2 | `85` | `true` | 85 |
| 3 | `x` | `false` | 0 |

`int.TryParse()` возвращает `true`, если строку удалось преобразовать в целое число, и `false`, если не удалось. При неудаче параметр `out` получает значение `0`.

Если `TryParseScores` проверяет, что **все части** строки являются числами, он вернёт `false`: первая часть содержит имя, а последняя — символ `x`. Если метод должен извлекать только оценки, ему нужно пропустить часть с именем и отдельно определить, как обрабатывать некорректную оценку `x`.

## 3. Конкатенация строк и `StringBuilder`

Начальное значение: `s = ""`.

Цикл:

```csharp
for (int i = 0; i < 4; i++)
{
    s += i;
}
```

На каждой итерации создаётся новая строка, потому что строки в C# неизменяемы.

| Шаг | `i` | Значение `s` после операции |
|---:|---:|---|
| 1 | 0 | `0` |
| 2 | 1 | `01` |
| 3 | 2 | `012` |
| 4 | 3 | `0123` |

Итого: выполняются 4 конкатенации и создаются 4 новые строки. Начальная пустая строка `""` — отдельное исходное значение.

Вариант со `StringBuilder`:

```csharp
var sb = new StringBuilder();

for (int i = 0; i < 4; i++)
{
    sb.Append(i);
}
```

| Шаг | `i` | Содержимое `StringBuilder` |
|---:|---:|---|
| 1 | 0 | `0` |
| 2 | 1 | `01` |
| 3 | 2 | `012` |
| 4 | 3 | `0123` |

`Append()` дописывает символы в буфер `StringBuilder`, не создавая новую строку на каждой итерации. Создаётся один объект `StringBuilder`; его внутренний буфер может выделяться или расширяться по мере необходимости. Если вызвать `sb.ToString()`, будет создана итоговая строка.

## 4. Почему `s.ToUpper()` не изменяет `s`

Строки в C# неизменяемы. Метод `ToUpper()` возвращает строку с заглавными буквами, но не меняет исходную строку.

Например:

```csharp
string s = "hello";
s.ToUpper();

Console.WriteLine(s); // hello
```

Чтобы сохранить результат, нужно присвоить его переменной:

```csharp
s = s.ToUpper();

Console.WriteLine(s); // HELLO
```
